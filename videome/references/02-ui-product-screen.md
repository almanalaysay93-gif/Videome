## 4. Prompt bar

## 5. Storyboard deck
**Use/context:** Explain a process, campaign, or creative concept as a sequence of panels.
**Build:** Establish one panel grid; reveal panels in narrative order with consistent gutters; animate a marker/highlight across the selected frame; land on the hero panel or completed board. Keep panel labels concise.
**Agent 3 build brief:** Turn the requested process into a storyboard-deck sequence with a clear reading order and one highlighted panel at a time. Preserve supplied frames, keep panel count manageable, and finish on the key frame.

## 7. Film scanner
**Use/context:** Make footage selection/editing tangible: a scan beam travels across frames and selects the usable take.
**Build:** Lay out a filmstrip/contact sheet; move a scanning line across thumbnails; briefly enlarge or outline the selected frame; transition from selected still to its full clip. Don't imply forensic scanning or real analysis if it's just a visual metaphor.
**Agent 3 build brief:** Build a film-scanner selection effect from the provided clips/stills. Highlight the intended take accurately, reveal it as the chosen shot, and keep labels/frame order faithful to the actual assets.

**Build:** Compose a simplified timeline with video/audio tracks and labeled blocks; animate a playhead through a few edits; show a trim, ripple, or audio sync only if the footage supports it; resolve to the finished frame. Keep it legible, not a full fake interface.
**Agent 3 build brief:** Build a simplified, truthful NLE-timeline visual for the edit being described. Use actual shot order and meaningful track labels; avoid fake branded software UI and finish on the result.

## 14. Playing grid
**Use/context:** Showcase a collection of clips or multiple product use cases simultaneously.
**Build:** Arrange a 2×2 or 3×3 grid; stagger clip start times; assign one cell as the focus with subtle scale/border; collapse or cut to the chosen clip. Preserve consistent crops and avoid tiny text.
**Agent 3 build brief:** Build a synchronized playing grid from the supplied clips. Keep every tile recognizable, stagger starts deliberately, and provide a clear focal tile and transition to the hero shot.

## 15. Reel feed
**Use/context:** Simulate browsing several short pieces before stopping on the one that matters.
**Build:** Create a vertical feed stack with minimal generic controls; scroll through 2–4 distinct clips; stop decisively on the target; transition into full-screen playback. Avoid copying a platform's protected interface unless the user provides/authorizes it.
**Agent 3 build brief:** Build a generic reel-feed scroll using supplied clips, stopping on the specified one. Keep platform chrome generic, avoid invented engagement counts, and make the stop/zoom readable.

## 16. Video card
**Use/context:** Package a clip as a clickable-looking preview in a product page, portfolio, or case study.
**Build:** Place a thumbnail in a card with concise title/metadata; animate play icon or progress strip; expand from card to full-frame footage; use authentic supplied copy and image. Avoid tiny metadata.
**Agent 3 build brief:** Build a video-card preview-to-play transition for the specified clip. Preserve supplied title/thumbnail, keep controls generic unless actual UI is supplied, and resolve to the full footage.

## 17. Everpresent CTA
**Use/context:** Keep one clear next step visible through a short promotional edit without interrupting the main content.
**Build:** Reserve a consistent safe-area corner/edge; show a compact button/label with a restrained entrance; maintain steady position and contrast; allow it to soften or clear during critical face/copy moments. Keep CTA wording exact.
**Agent 3 build brief:** Add the requested CTA as a stable, low-distraction overlay across the specified beats. Preserve exact CTA text and safe areas, and never cover the subject or essential captions.

## 18. Comment drop
**Use/context:** Let one authentic viewer comment land as a reaction or proof point.
**Build:** Use an actual approved comment or explicitly supplied fictional copy; animate one card in from the edge; hold for reading; dismiss or connect it to the relevant response. Hide personal data unless approved.
**Agent 3 build brief:** Animate the exact approved comment as one readable comment card, timed to the related moment. Do not invent testimonials, usernames, or outcomes; respect privacy and clear the overlay cleanly.

## 21. UI world
**Use/context:** Let an interface become a physical environment—for example, walking through a dashboard or feature map.
**Build:** Separate the UI into depth layers; select one path through the interface; animate camera movement between panels; preserve readable content and consistent perspective. Use actual interface screens or mark mockups as conceptual.
**Agent 3 build brief:** Build a UI-world sequence from supplied screens, guiding the viewer through one feature path. Preserve the real UI and labels; use depth only to clarify navigation, not to imply nonexistent functions.

## 24. Phone mockup
**Use/context:** Show an app, message, or vertical video in a device frame as contextual proof.
**Build:** Use a neutral or supplied device frame; place screen capture within correct aspect ratio; animate slight tilt/entry; cut or push through screen to full view. Check notch/status bar and avoid invented system details.
**Agent 3 build brief:** Place the supplied screen/video in a realistic, neutral phone frame and transition into it. Preserve screen pixels/aspect, avoid fake notifications or unsupported UI, and keep screen content readable.

## 44. Screen record + cursor
**Use/context:** Teach one workflow or prove a product interaction clearly.
**Build:** Capture the real screen at sufficient resolution; crop around the target; enlarge/highlight cursor clicks; pause on consequential result; add concise step labels only when they help. Mask sensitive data and remove idle cursor wandering.
**Agent 3 build brief:** Edit the real screen recording into a clear workflow demo. Highlight only the necessary cursor actions, preserve true app behavior, redact private data, and hold on the outcome long enough to understand.
